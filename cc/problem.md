你有一个长度为**奇数** n 的数组 a，由正整数组成。你需要将序列划分成若干个**奇数长度**的子数组*，且所有子数组具有相同的**中位数****。目标是最大化子数组的数量。

形式化地：你需要找到一个严格递增的序列 k，长度为 (p+1)，其中 k₁=1，k_{p+1}=n+1，使得对于每个 1 ≤ i ≤ p，序列 [a_{k_i}, a_{k_i+1}, …, a_{k_{i+1}−1}] 的中位数全都相同。并且 k_i 与 k_{i+1} 的奇偶性必须不同。求最大的 p。

> * 数组 b 是数组 a 的子数组，当且仅当 b 可以通过删除 a 开头的若干个（可能为 0 个或全部）元素以及末尾的若干个（可能为 0 个或全部）元素得到。

> ** 一个长度为奇数 x 的数组的**中位数**，定义为将数组按非降序排序后的第 ⌈x/2⌉ 个元素。
